# No.35 隙間探索 — 非直積型の帽子推測障害

**v0.1について外部監査のPASS報告を受領。公開・新規性認定・Windows実機再現は未実施。v0.2の新しい補題と探索は未外部監査。**

仮題: **Non-Box Obstructions for Proper Hat Guessing on Book Graphs**

## 今回の候補

背骨が k 個、ページが n 枚のブックグラフ B_{k,n}=K_k join 独立集合について、適正彩色の帽子推測数の候補上界を得た。

    HGP(B_{k,n}) <= 1 + sum_{r=1}^k r^r + k^2   (k>=3, n>=1).

| 背骨 k | Zhai v3 の最適化済み直積障害の上界 | 今回の候補上界 |
|---:|---:|---:|
| 3 | 46 | 42 |
| 4 | 317 | 305 |
| 5 | 3526 | 3439 |

これは全てのページ数 n に対する上界で、特定の対称戦略だけの上界ではない。任意の頂点別・決定的局所戦略を扱う。一方、上界で勝てる構成や厳密値は得ていない。

## 何が既知で、何を候補とするか

- **既知:** 1+sum r^r 個の非被覆点集合を作る再帰。Gadouleau に由来し、He–Ido–Przybocki (2022) の EJC出版版 Lemma 11 / Figure 1（arXiv版 Lemma 2.6 / Figure 1） に掲載されている。33点の幾何自体を今回の発見とはしない。
- **既知:** 被覆を可視入力スロットのマッチングへ直す方法。適正彩色版の |P|+|supp(P)| と C_k の定式化、escape/guarding 法は Zhai の枠組みを引き継ぐ。
- **候補として残す部分:** 既知の再帰構成を、各タプルが適正なまま k^2 色だけで表す具体的な再標識。これによる一般上界と、全ての k>=3 で完全な直積障害が最適にならないという帰結。
- この組合せは短い。独立した論文としての新規性・重要性があるかは、数式の正しさと分けて監査する。別名・既知の一般帰結・非公開の同時期結果まで網羅したとは主張しない。

## k=3 の手で追える証拠

    A={0,1,2}, B={3,4,5}, D={6,7,8}
    P=(A x B x D) union ({0,1} x B x {2}).

33個の適正な３つ組、９色。各座標を除いた投影は12・11・９種類で、合計32種類しかない。３本の背骨の正解で覆えるスロットが33点に足りない。したがって非被覆障害になり、C_3<=42。

９色の障害を43色パレット内で利用して「43色ではどんな戦略も勝てない」と示す。42色で勝てる戦略、C_3=42、有限の安定化ページ数を示したわけではない。既知定理からの下界と合わせた今回の範囲は39<=C_3<=42。

一般証明は PROOF.md の帰納法と直接のゲーム論証に記載。有限検算だけで全 k の定理を置き換えていない。

## 先に試した５ページ問題

B_{2,5}の値は、Zhai v3 の表6で７または８となっている。GF(8)上の既知の５ページ・アフィン戦略６種類が、それぞれ32768ページベクトル中224件で失敗することを検証器の対照として確認した。

その後、g_j(x,y)=x XOR h_j(x XOR y) という平行移動に追随する制限クラスで、SATによる反例誘導探索を実施した。初回は約154秒、275反復、73929反例節で UNKNOWN_LIMIT。割込み用タイマーの処理に例外が出たため、対応するバックエンドへ変更し、約８秒の再実行で正常にUNKNOWN_LIMITを記録した。初回結果と修正版の動作確認結果を分けて保存。

**SAT・UNSATの結論はいずれも得ていない。** 制限クラス内の不存在も、任意戦略での値７も主張できない。探索の不成立を新しい数学的反例とは扱わない。No.35の一般上界はこのSAT探索に依存しない。
